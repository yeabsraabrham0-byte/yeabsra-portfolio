# Yeabsra Portfolio

## Before publishing
1. Open `index.html`.
2. Replace `your-email@example.com` with your real email.
3. Replace the GitHub placeholder with your GitHub profile URL.
4. Update the skills/projects as you learn more.

## Publish with GitHub Pages
Create a GitHub repository (for example `yeabsra-portfolio`), upload these three files, then enable GitHub Pages from the repository settings.
